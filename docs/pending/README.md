# Funcionalidades e correções pendentes

Este diretório especifica apenas pendências inferidas do código, configurações e validações executadas. Prioridades usam a seguinte classificação:

- **Crítica:** bloqueia release ou pode comprometer pagamento, benefício, credencial ou dado sensível.
- **Alta:** deve ser resolvida antes da produção.
- **Média:** necessária para robustez, operação ou escopo declarado, mas não bloqueia isoladamente uma correção crítica.
