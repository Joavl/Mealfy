# Mealfy - Sistema de Doação de Alimentos

Este projeto é uma plataforma para facilitar a doação de alimentos, conectando doadores, famílias em necessidade e ONGs/Entidades parceiras.

## 🚀 Tecnologias Ativas (Atual)

- **Frontend:** React + TypeScript + Vite
- **Backend:** Node.js + Express + TypeScript + Prisma ORM + PostgreSQL
- **Mobile:** React Native + Expo

## 📂 Estrutura de Pastas

- `/src`: Código fonte do Frontend React Web.
- `/backend`: API oficial em Node.js com TypeScript e Prisma.
- `/mobile`: Código fonte do aplicativo mobile nativo em React Native (Expo).
- `/public`: Assets públicos do frontend.

## 🛠️ Como rodar o projeto

### 1. Backend API (porta 3001)
Instale as dependências e inicie o servidor:
```bash
cd backend
npm install
npm run dev
```

### 2. Frontend Web (porta 5173)
Na pasta raiz do projeto:
```bash
npm install
npm run dev
```
