# Mealfy - Sistema de Doação de Alimentos

Este projeto é uma plataforma para facilitar a doação de alimentos, conectando doadores, famílias em necessidade e ONGs.

## 🚀 Tecnologias Ativas (Atual)

- **Frontend:** React + TypeScript + Vite
- **Backend (Mock):** Node.js + Express + TypeScript
- **Mobile:** Preparado para Capacitor / Mobile-first Design

## 📂 Estrutura de Pastas

- `/src`: Código fonte do Frontend React.
- `/backend`: Backend atual em Node.js (Serviços e Mocks).
- `/legacy-csharp-backend`: Versão arquivada do backend em C# .NET (para referência).
- `/public`: Assets públicos do frontend.

## 🛠️ Como rodar o projeto

1. Instale as dependências:
   ```bash
   npm install
   ```
2. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```
